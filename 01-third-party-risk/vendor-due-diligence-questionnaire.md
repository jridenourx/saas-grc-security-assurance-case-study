# Vendor Security Due Diligence Questionnaire

## 1. Purpose

This questionnaire establishes a consistent process for evaluating the security and operational risks associated with third-party service providers used by Northstar Cloud Solutions.

It is intended to support vendor onboarding, periodic reassessment, material service changes, and risk-based due diligence.

This is a simulated questionnaire for a fictional organization. Any completed responses created for this portfolio must be identified as synthetic.

## 2. Instructions for Respondents

For each question, provide one response:

* **Yes:** The control or practice is implemented as described.
* **Partially:** The practice exists but has limitations or incomplete coverage.
* **No:** The practice is not implemented.
* **Not Applicable:** The question does not apply; provide a rationale.
* **Unknown:** The respondent cannot confirm the current state.

A response of "Yes" does not, by itself, establish that a control is effective. Supporting evidence should be provided where requested.

Do not submit confidential information through this simulated exercise. Evidence should be sanitized and should not include real credentials, personal information, customer records, or sensitive system details.
